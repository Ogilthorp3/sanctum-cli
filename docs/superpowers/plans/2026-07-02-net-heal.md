def _p(**k):
    base=dict(iface="en1",config_method="DHCP",ip="10.0.0.10",subnet="255.255.255.0",
              gateway="10.0.0.1",gateway_reachable=True,associated=True,on_tailnet=True,tb5_up=True)

    d=diagnose_posture(_p(gateway_reachable=False)); assert d.verdict=="GATEWAY_DEAD" and d.action.kind=="dhcp_renew" and d.action.safe

def test_double_nat_overlap_is_risky():
    d=diagnose_posture(_p(gateway_reachable=False), overlap=True); assert d.verdict=="DOUBLE_NAT_OVERLAP" and not d.action.safe

- [ ] **Step 3 — implement**: `HealAction(kind: str, safe: bool, detail: str)`, `PostureDiagnosis(verdict, detail, remedy, action, posture)`. `diagnose_posture(posture, *, overlap: bool=False)`: UNVERIFIED if no iface/config_method (fail-closed). ## Task 4: `sanctum net heal` CLI (dry-run / --apply, snapshot→verify→revert)
**Files:** extend `sanctum_cli/commands/net.py`; test `tests/test_net_cli.py`.
- Mirror the `sanctum link` command patterns (`commands/link.py`: `_report`, injected seams, `typer.Option`, Rich `escape`, honest-verify).
- `net heal` default = **dry-run**: `probe_posture → diagnose_posture → plan_heal(dry)`; print posture + verdict + the would-do action + spine state. No mutation. Exit 0.
- `--apply`: execute a **safe** plan with **snapshot → act → verify-back → auto-revert**: snapshot current IPv4 config (`networksetup -getinfo "Wi-Fi"`), run the action (`flip_dhcp`=`networksetup -setdhcp "Wi-Fi"`; `dhcp_renew`=`ipconfig set en1 DHCP`), wait (bounded) for a lease + `gateway_reachable`, re-probe; if not healthy → revert to snapshot (`networksetup -setmanual …` with the saved values) + stop + alert. Print ✓ only from the real re-probe. If the plan is stop-and-alert → print the reason + the one-line manual fix, exit 0. (Mutations need root; the daemon runs as root — `--apply` from a non-root shell prints the sudo hint.)
- **Tests** (inject the runner — NO live networksetup/ipconfig): dry-run on a Manual-static fixture prints `STATIC_DRIFT`+`flip_dhcp`; `--apply` on a fixture where the simulated re-probe stays broken → asserts revert path taken; risky fixture → prints alert, no mutation.
- Commit `feat(net): net heal — dry-run + guarded --apply (snapshot/verify/auto-revert)`.
